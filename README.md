# Hands-On Data Lab Implementation

Task 2 of the YuvaIntern Data Engineer Internship.

## About
A Jupyter notebook that sets up a data science environment and works through practical exercises in data manipulation, visualization and basic analysis.

What is inside
- Environment setup (Python, NumPy, Pandas, Matplotlib)
- A practice dataset of 12 students (department, attendance, study hours, marks)
- Data manipulation: filtering, sorting, adding columns, group by
- Visualizations: bar chart, histogram, scatter plot, box plot
- Basic analysis: summary statistics and correlation heatmap
- An insight note after each result

Key findings
- Higher attendance and more study hours go with higher marks (correlation 0.994 and 0.987).
- The DS department has the highest average marks in this dataset.
- The dataset is made up for practice, so the results are not real-world findings.

Files
- `02_hands_on_data_lab.ipynb`: the main notebook

How to run
1. Install the libraries: `pip install numpy pandas matplotlib jupyter`
2. Run `jupyter notebook` and open `02_hands_on_data_lab.ipynb`
3. Click **Kernel, then Restart and Run All**
